## ▶️ How to Run

First, extract the "ML.zip" file or clone the repository. Then, ensure you have the required libraries installed:

```bash
pip install jupyterlab pandas numpy scikit-learn tensorflow
```

Run Jupyter Notebook in the directory:

```bash
jupyter notebook
```

Open any `.ipynb` file in your browser to run the cells.
